# kurgu — BorsaSemih Video Stüdyo

Claude ile ham Reels/YouTube videosunu profesyonel edite çeviren, ücretsiz ve bulutta çalışan stüdyo.

```bash
git clone --depth 1 https://github.com/semihsahinrr88-hash/kurgu ~/kurgu && bash ~/kurgu/setup.sh
```

| Klasör | İçerik |
|---|---|
| `SKILL.md` | Claude'un edit kuralları ve akışı (video-studyo skill'inin kaynağı) |
| `frame.md` | BorsaSemih görsel sistemi — renk, font, kart, hareket ve ses dili |
| `scripts/` | transkript (faster-whisper), Türkçe kelime hizalama (wav2vec2), otomatik kesim, altyazı, sahne kütüphanesi, ses efekti, export + kapak |
| `fonts/` | Montserrat, JetBrains Mono (Türkçe karakterli) |
| `sfx/` | 16 lisanslı ses efekti (Pixabay Content License) |
| `templates/` | GSAP (yerel) |
| `docs/` | Ek tarifler |

Temel: [video-use](https://github.com/browser-use/video-use) + [HyperFrames](https://github.com/heygen-com/hyperframes).
